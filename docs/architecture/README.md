## 文档约定

- **一模块一文件**：新增设计/决策写进对应模块文档，不新建"大而全"的杂项文档。
- **只写现状与结论**：不写演进流水账、版本时间线；需要溯源的可给出处。
- **序号文档内自洽**：各文档章节从 1 起独立编号，跨文档引用写清"文档 + 节"。
- **字段/参数为唯一事实来源**：数据模型以 [01](01-core-data-model.md) / [05](05-topic-clustering.md) 为准，接口以 [02](02-api-contract.md) 为准，配置以 [06](06-engineering.md) + `config_schema.py` 为准。
- **剔除环境细节**：不写具体主机/路径/端口/凭据/"实测环境"等仅本机适用或敏感信息。
