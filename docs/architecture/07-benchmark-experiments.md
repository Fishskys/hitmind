# 07 · 基准与实验

> 模块文档 · HitMind 架构文档集（索引见 [README](README.md)）。

**范围**：评测基准口径、当前成绩、错题结构与已采纳的检索/时间改造

## 1. 评测基准（chat-memory-benchmark）

端到端验收基准（外部开源项目，MIT）。

- **规模**：多人物长对话数据集，6 个人物、历史共约 2300+ 回合、**714 题**、约 190 个事实组。
- **题结构**：多为同一事实组在多个时距各问一次（`d00/d03/d15/d45` = 最后提及后 0/3/15/45 天），直测衰减 vs 召回。
- **判分**：非字符串匹配。每题 `rubric{required, forbidden, unknown, acceptable, tag_scoring}`，LLM 语义判读；`required` 全满足且无 `forbidden` 才通过。
- **考点**：可重叠的多类题型（第三方事实、边界、偏好、计划、改口、纠错、没解释的矛盾、相似事件、相对日期、资料不足…）——考跨轮拼线索、条件期限、诚实边界，不是简单查事实。
- **接入口径**：每人隔离 DB；按 `cutoff_turn` 升序增量把回合用 `Engine.capture()`（raw，跳写闸门）灌入，时间戳=数据集给出的逻辑时间；到截止点 `recall` top-k → 只把召回记忆+问题交统一 QA 模型作答 → `answers.jsonl` → 判分。
- **记忆注入格式**（与生产一致）：每条召回渲染为 `[id] (kind)[@created_at 日期]：正文`，正文取**原文 `content`**（`normalized_text` 仅用于检索索引，不注入作答上下文）。

## 2. 当前成绩（已提交插件 · 714 题全量）

条件：`top_k=10`、raw capture（逐轮不做 LLM 抽取/定稿）、dense+BM25 混合检索、`dense_floor=0.50`、时间归一化开启（归一文本仅索引）、记忆注入 `[id] (kind)[@date]：原文`。分两档：无 rerank（`NullReranker`）、有 rerank（本地 cross-encoder `/rerank`，`rerank_pool=30`，fail-open）。

| 档 | 通过 | 正确率 |
|---|---|---|
| 无 rerank | **631 / 714** | **88.4%** |
| 有 rerank | **660 / 714** | **92.4%** |

- **rerank 净增益 +29**（相对无 rerank）：由错转对 42、由对转错 13。
- 对照历史口径（同一数据集、早期注入/时间戳版本，逐题重判）**604/714 = 84.6%**：本版无 rerank 净 **+27**（转对 57 / 转错 30），有 rerank 净 **+56**（转对 74 / 转错 18）。提升主要来自"记忆注入 `[@日期]`+原文（不注入归一文本）+ 提示词规范"。

## 3. 错题结构与弱项分析

- **错否**是最大残余错误（有 rerank 仍 28 次）：记忆里有、作答却否认。根因不在推理，而在**召回未把"更新/另一说法/相关旧轮"带进 top-k**——典型于"真实变化/约定和欠账/分散的线索/没解释的矛盾"这类需要跨轮拼合或识别"后来改了"的题。
- **编造日期**（8→13）：相对日期题里，模型据 `[@date]` 推算绝对日期时偶尔越界或算错；提示词已约束"仅时间题可按片段 [@date] 换算、非时间题不报日期"，绝大多数受控，残余为个别推算错误。
- **错认 / 越界 / 不当私事披露**：少量，属边界与隐私纪律，提示词层面已规范。

## 4. 已采纳的检索/时间改造（现状）

- **阈值卡原始信号**：dense 用绝对余弦门槛 `dense_floor`（默认 0.50），BM25 支持绝对/相对下限；无相关返回空。
- **融合**：RRF（默认）或归一化加权线性；`rel_norm` 为相对名次分。
- **二级 rerank（cross-encoder）**：`top_k` 前用本地 `/rerank` 对短名单重排，fail-open（禁用/超时/异常保留一阶段序）。本版实测净增益 +29，主要降"错否"。
- **主题扩展**：命中任一带 topic 的记忆后，按前 N 条命中的 topic 追加同主题记忆（[05](05-topic-clustering.md)）。
- **时间归一化**：写入时把相对日期按逻辑时间补成绝对日期（[01 §3](01-core-data-model.md) `normalized_text`），**仅作检索索引**；作答侧以 `[@created_at 日期]` 标注每个片段的"说出口期"来支撑相对日期换算。
- **记忆注入与作答提示词**：召回统一注入 `[id] (kind)[@date]：原文`；作答提示词约束"必须使用片段证据、仅时间题可按 [@date] 换算、非时间题不主动报日期、冲突指出不一致、不主动提隐私/无关旧事"。

> 说明：raw 评测逐轮 `capture`、不做 LLM 定稿，故 `topic` 全空 → 主题扩展在纯 raw 评测里基本不生效；其价值在真实产品路径（有离线 LLM 定稿）体现。

## 5. 结论与后续

- 当前已提交插件在 714 题上达到 **无 rerank 88.4% / 有 rerank 92.4%**，较历史基线显著提升。
- 后续优化优先级：①针对"错否"从**召回侧**提升（把更新/冲突/多跳相关轮纳入 top-k）；②"编造日期"再收紧（提示词+日期标注配合）；③长时距 d45 的稳定性。
