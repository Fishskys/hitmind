# 07 · 基准与实验

> 模块文档 · HitMind 架构文档集（索引见 [README](README.md)）。

**范围**：评测基准口径、当前成绩、漏召回诊断与已采纳的检索改造

## 1. 评测基准（chat-memory-benchmark）

端到端验收基准（外部开源项目，MIT）。

- **规模**：多人物长对话数据集，6 个人物、历史共约 2300+ 回合、**714 题**、约 190 个事实组。
- **题结构**：多为同一事实组在多个时距各问一次（`d00/d03/d15/d45` = 最后提及后 0/3/15/45 天），直测衰减 vs 召回。
- **判分**：非字符串匹配。每题 `rubric{required, forbidden, unknown, acceptable, tag_scoring}`，LLM 语义判读；`required` 全满足且无 `forbidden` 才通过。
- **考点**：可重叠的多类题型（第三方事实、边界、偏好、计划、改口、纠错、没解释的矛盾、相似事件、相对日期、资料不足…）——考跨轮拼线索、条件期限、诚实边界，不是简单查事实。
- **接入口径**：每人隔离 DB；按 `cutoff_turn` 升序增量把回合用 `Engine.capture()`（raw，跳写闸门）灌入，时间戳=逻辑时间；到截止点 `recall` top-k → 只把召回记忆+问题交统一 QA 模型作答 → `answers.jsonl` → 判分。

## 2. 当前成绩（714 题全量，top_k=10，raw capture，混合检索，含 topic 定稿）

**604 / 714 ≈ 84.6%**。

- 按题型通过率由低到高（样本≥20）：**相对日期 11.4%**、**时间题 20.8%**、分散的线索 64.3%、时间约定 69.8%、没解释的矛盾 70.2%、职业 74.5%、计划 78.5%、真实变化 79.3%、约定和欠账/生日/相似事件 80%、用户基本信息 82.1%、改口 82.5%、偏好/转述 86.4%、第三方事实 87.7%…（边界、助手自己说过的话、纠错、资料不足、假设、计划假设梦转述猜测均在 91% 以上）。
- 按人物：P01 85.2%、P12 78.5%、P14 87.8%、P16 89.4%、P17 82.0%、P20 84.7%。
- 按时间距离基本持平（d0 84.7 / d3 83.2 / d15 85.6 / d45 85.0）→ 短板不是"越久越忘"，而是特定题型（时间类、多跳类）系统性偏弱。

**错题结构（110 道失败）**：`错否`（记忆里有、却答"没有/不知道"）占 ~60%，是最典型的"检索/上下文问题"而非推理问题；其余为错认、无关旧事、未知当事实等。

## 3. 漏召回诊断（针对"错否"题）

对"错否"类失败题做逐题解剖（在按时间点截断的忠实库上复跑召回），结论：

- **多数"错否"并非真的没召回**：其 ground-truth 源轮常能进 top-k（甚至第 1 名），失败在于**大量同主题轮次把证据淹没**——注入条数过多、作答未能取用。
- **真·漏召回**的主因：① 查询与证据**字面/语义不重合**（指代、词汇差异，余弦偏低）；② 长历史里证据被**大量相似轮次稀释**、在融合/截断时被挤出；③ 阈值（dense 底噪、精确度）设定。
- 用"按时间点截断库 + 真实召回"对比，能把问题定位到"阈值误杀 / 融合幅度 / 语义不匹配 / 注入淹没"四类。

## 4. 已采纳的检索改造（现状）

- **阈值卡原始信号**：dense 用绝对余弦门槛 `dense_floor`（默认 0.50），BM25 支持绝对/相对下限；无相关返回空。（此前"余弦当主题判据不可行"已被数据证伪：同事实对余弦可能低于不同话题对。）
- **融合**：RRF（默认）或归一化加权线性；`rel_norm` 为相对名次分。
- **二级 rerank（cross-encoder）**：`top_k` 前用本地 `/rerank` 对短名单重排，fail-open。定向验证显示可把"语义对但名次被摊薄"的难例拉回 top-k。
- **主题扩展**：命中任一带 topic 的记忆后，按前 N 条命中的 topic 追加同主题记忆（[05](05-topic-clustering.md)）。
- **时间归一化**：写入时把相对日期按逻辑时间补成绝对日期（[01 §3](01-core-data-model.md) `normalized_text`），直击"相对日期/时间题"弱项。
- **查询改写**：确定性同义/疑问词扩展 + 多路召回按最优名次合并。

> 说明：raw 评测逐轮 `capture`、不做 LLM 定稿，故 `topic` 全空 → 主题扩展在纯 raw 评测里基本不生效；其价值在真实产品路径（有离线 LLM 定稿）体现。
